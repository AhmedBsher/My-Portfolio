# 🚀 Ahmed Bsher | Mechanical Engineering & Web Development Portfolio

This is the source code for AhmedBsher's personal website—a premium, interactive platform designed to showcase professional expertise in Mechanical Engineering and Front-End Web Development. The site features advanced UI/UX components, modular sections, and a responsive design tailored for all devices.

![Portfolio Preview](images/icon.png)

## ✨ Key Features

*   **Interactive UI/UX**:
    *   **Magnetic Navigation**: Links that dynamically pull toward the cursor, creating a tactile and responsive feel.
    *   **Custom Cursor System**: A specialized cursor and follower that interact with links, buttons, and cards.
    *   **Hero Particle System**: A canvas-based particle network providing a dynamic visual backdrop for the hero section.
    *   **Text Scramble Effect**: Animated headlines that "decrypt" into clear text upon loading.
*   **Modern Aesthetics**:
    *   **Glassmorphism**: Frosted-glass card designs with real-time backdrop blur and subtle borders.
    *   **Scroll Reveal Logic**: Sophisticated entrance animations for sections using the `IntersectionObserver` API.
    *   **Premium Typography**: Driven by Google's Poppins typeface for maximum readability.
*   **Robust Functionality**:
    *   **Project Filtering**: Instant filtering system to toggle between Web and Mechanical projects.
    *   **Project Modals**: Deep-dive modals for project details, featuring tech stack badges and feature lists.
    *   **Responsive Timeline**: A vertical "Journey" experience that adapts to mobile screens.

## 📁 Project Structure & Sections

### 🛠️ Technical Files
- **`index.html`**: The semantic core of the website, containing all content blocks and structure.
- **`style.css`**: A highly modular CSS architecture utilizing CSS variables (design tokens) for easy theme management.
- **`scripts.js`**: Custom JavaScript logic for navigation, magnetic effects, filtering, and animations.
- **`images/`**: Optimized directory for project screenshots, brand icons, and background assets.

### 🏛️ Website Sections
- **Header**: Features the logo, magnetic navigation links, and a scroll progress bar.
- **Main Section (Hero)**: The landing area with particle effects, a greeting message, and social icons.
- **Info**: A brief professional introduction and academic background.
- **Journey (Experience)**: A timeline-based walkthrough of academic milestones and professional growth.
- **Services**: Highlights core offerings, including AutoCAD design, SolidWorks, and Web Development.
- **Projects**: A filtered gallery of work with detailed modal pop-ups.
- **Abilities (Skills)**: An interactive Swiper.js slider showcasing technical proficiencies with animated progress bars.
- **Soft Skills**: A unique circular "orbit" layout visualizing interpersonal strengths.
- **Contact**: A glassmorphic contact form and direct links for phone, email, and location.
- **Footer**: Copyright information and secondary social navigation.

## 🛠️ Tech Stack

*   **Languages**: HTML5, Vanilla CSS3, JavaScript (ES6+)
*   **Libraries**: 
    *   [Swiper.js](https://swiperjs.com/) (Technical skills carousel)
    *   [FontAwesome](https://fontawesome.com/) (Iconography)
*   **Engineering Tools**: SolidWorks, MATLAB, AutoCAD, ANSYS (Assets generated via these tools)
*   **Deployment**: Git, GitHub Pages

## 🚀 Quick Start & Usage

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/AhmedBsher/My-Portfolio.git
    ```
2.  **Run locally**:
    Open `index.html` in any modern web browser. No compilation or server setup is required.
3.  **Customization**:
    Feel free to modify the `style.css` variables to change the accent colors or update project data in `index.html`.
